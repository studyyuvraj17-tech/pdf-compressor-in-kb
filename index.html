Understand KB, KiB and strict upload limits

File-size labels are not always used consistently. This tool interprets 1 KB as 1,024 bytes (the binary unit often called KiB). Some upload portals describe a limit in KB while applying a decimal 1,000-byte calculation. That difference can matter when a file is very close to the stated limit.

For a strict maximum, do not aim exactly at the limit. Choose a lower target where the document remains readable, download the result, and check the file's exact size in your device's file information. The receiving portal's own validation is the final test.

  • Check the portal's rule: confirm whether it gives a maximum in KB or MB and whether it lists a separate page-count limit.
  • Leave a margin: a file a little below the limit is safer than one that sits on the boundary.
  • Check the downloaded file: do not rely only on a rounded size label shown by an operating system.

What changes when a PDF is compressed?

A PDF can contain selectable text, vector graphics, scanned page images, photographs, fonts, links and interactive form fields. These elements do not all compress in the same way. A file that is already optimized may barely shrink, while a scanned document may become smaller only after reducing image resolution or quality.

Lossless re-save

The tool first attempts to save the PDF again with optimized PDF structures. This route is intended to preserve the original page content and selectable text, but it may produce little or no reduction.

Image-based reduction

If a smaller file is needed, the tool can render pages and build a new PDF from page images. This can reduce size more substantially, but text may no longer be selectable and links, form fields, bookmarks or accessibility structure may not survive.

Quality trade-off

Lower resolution and stronger JPEG compression reduce file size at the cost of detail. Small characters, fine lines, QR codes, stamps and signatures need particular attention.

For that reason, a successful size reduction is not by itself proof that a document is suitable for submission. Open the downloaded file and inspect every page at normal and enlarged size.

PDF submission checklist

Before uploading a compressed document to an examination form, recruitment portal, college application or other online service, check the following:

  • Correct document: confirm that you selected the intended PDF and that every required page is present and in the correct order.
  • Readable details: zoom in on names, dates, identification numbers, small print, signatures, stamps and photographs.
  • File requirements: check the portal's maximum size, accepted file type, page limit and any image or scan requirements.
  • PDF functionality: if the form needs selectable text, clickable links, fillable fields or accessibility features, verify these after compression. Image-based output may not retain them.
  • Final upload check: use the downloaded output, not the original file, and confirm that the portal accepts it.

If the result is too blurry or remains above the limit, return to the original PDF and try a less aggressive target. Do not submit an unreadable document simply to meet a file-size number.

About this tool and its maintenance

PDFCompressInKB is an independent browser-based utility. The project source code and public issue tracker are available on GitHub. The compressor uses browser-side PDF processing libraries; the site does not claim that every PDF can reach every target without quality loss.

Users can report a bug or suggest an improvement through the contact page. Please do not post private documents or personal information in public issue reports.
