Elaborazione dei PDF

PDFCompressInKB è progettato per elaborare i file PDF nel browser. Nel normale flusso, il PDF selezionato non viene intenzionalmente caricato su un server di compressione.

Dati tecnici

Il browser può mantenere temporaneamente in memoria il file selezionato e i dati generati durante l'elaborazione. Se in futuro saranno attivati strumenti di analisi, pubblicità o altre funzioni di terze parti, potranno essere trattati dati tecnici secondo le relative configurazioni e informative.

Cookie e servizi di terze parti

Cookie o tecnologie simili possono essere utilizzati quando necessari per analisi, pubblicità o funzionalità. Quando richiesto dalla legge, verrà richiesto il relativo consenso.

Modifiche

Questa informativa può essere aggiornata quando cambiano il sito, i servizi utilizzati o i requisiti applicabili.
