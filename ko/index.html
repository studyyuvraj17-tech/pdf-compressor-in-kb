PDF 압축 온라인 무료

PDF를 온라인에서 무료로 압축하세요. PDF 파일 크기를 줄이고 100KB, 200KB, 500KB 또는 1MB로 압축할 수 있습니다. 프로그램 설치 없이 브라우저에서 사용하세요.

PDF를 원하는 KB 크기로 압축하는 방법

  1. PDF 업로드: PDF를 선택하거나 압축기로 끌어다 놓습니다.
  2. 목표 크기 입력: 100KB, 200KB, 500KB 또는 1MB를 선택합니다.
  3. PDF 압축: 압축을 클릭하면 브라우저에서 PDF를 최적화합니다.
  4. 결과 다운로드: 처리가 끝나면 압축된 PDF를 다운로드합니다.

この PDF 압축기를 사용하는 이유

특정 파일 크기 설정

Set a target in KB instead of choosing only a generic compression level. This is useful when an application, form or website has a file-size limit.

간단한 브라우저 작업

Upload a PDF, choose a target, compress it and download the result without installing desktop software.

품질을 먼저 보호

The compressor first attempts to preserve quality and only makes stronger reductions when the requested target requires them.

자주 묻는 질문

PDF를 100KB로 압축하려면 어떻게 하나요?

PDF를 선택하고 목표 크기에 100KB를 입력한 다음 압축을 클릭하세요. 선택한 크기에 맞도록 PDF를 최적화합니다.

PDF를 200KB로 압축할 수 있나요?

네. 압축을 시작하기 전에 목표 크기로 200KB를 입력하세요.

PDF 파일을 온라인에서 200KB로 줄이려면 어떻게 하나요?

PDF를 업로드하고 목표 크기를 200KB로 설정한 다음 압축을 클릭하세요. 가능한 한 높은 품질을 유지하면서 파일 크기를 줄입니다.

품질 저하 없이 PDF를 200KB로 압축할 수 있나요?

200KB로 압축할 때 가능한 한 품질을 유지하도록 처리합니다. 큰 폭의 용량 감소가 필요한 경우 일부 품질 저하는 불가피할 수 있습니다.

이 PDF 압축기는 무료인가요?

네. PDF 압축기는 무료로 사용할 수 있습니다.

프로그램을 설치해야 하나요?

아니요. 설치가 필요하지 않습니다. JavaScript를 지원하는 최신 브라우저만 있으면 됩니다.

PDF 압축 프로그램을 설치해야 하나요?

아니요. 별도의 프로그램 설치 없이 최신 브라우저에서 PDF를 압축할 수 있습니다. PDF를 업로드하고 목표 크기를 설정한 뒤 압축하세요.

어도비 PDF 압축 없이 PDF를 압축할 수 있나요?

네. Adobe 프로그램을 설치하지 않고도 최신 브라우저에서 PDF를 압축할 수 있습니다. PDF를 업로드하고 목표 크기를 설정한 뒤 압축하세요.

참고: 큰 폭의 용량 감소가 필요한 경우 압축 과정에서 페이지가 이미지로 변환될 수 있으며, 이 경우 결과 PDF에서 텍스트 선택이 제한될 수 있습니다.
