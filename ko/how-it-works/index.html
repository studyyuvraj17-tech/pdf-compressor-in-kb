PDFCompressInKB 사용 방법

  1. PDF 압축기를 열고 PDF 파일을 선택합니다.
  2. 목표 크기를 KB 단위로 입력하거나 미리 설정된 크기를 선택합니다.
  3. 압축을 클릭하고 처리가 끝날 때까지 기다립니다.
  4. 생성된 PDF를 다운로드한 뒤 파일 크기와 품질을 확인합니다.

처리는 브라우저에서 실행됩니다. 복잡한 PDF는 품질 저하 없이 목표 크기에 도달하지 못할 수 있습니다.
