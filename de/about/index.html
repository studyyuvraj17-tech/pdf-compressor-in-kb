Über PDFCompressInKB

PDFCompressInKB ist ein einfaches Online-Tool, mit dem PDFs auf eine bestimmte Größe wie 100 KB, 200 KB, 500 KB oder 1 MB reduziert werden können.

Unser Ziel

Wir möchten die Komprimierung auf eine Zielgröße ohne Desktop-Software einfach machen.

Funktionsweise

Der Kompressor verarbeitet das Dokument im Browser und versucht, es auf die ausgewählte Größe zu reduzieren.

Qualität ist wichtig

Zuerst wird eine verlustfreie Optimierung versucht. Bei stärkerer Komprimierung können Seiten als Bilder verarbeitet werden, wodurch Textauswahl und Bildqualität beeinflusst werden können.

Wichtige Einschränkung

Nicht jedes PDF kann eine bestimmte Zielgröße ohne deutliche Qualitätsänderung erreichen.
