Comment fonctionne PDFCompressInKB

1. Choisissez un PDF

Sélectionnez un PDF sur votre appareil ou faites-le glisser dans le compresseur.

2. Définissez la taille cible

Choisissez 100 Ko, 200 Ko, 500 Ko ou 1 Mo.

3. Optimisez le PDF

L'outil tente d'abord une réenregistrement sans perte. Si nécessaire, il utilise une compression plus forte basée sur les images.

4. Créez le PDF compressé

Lorsque la compression par image est nécessaire, les pages sont rendues dans le navigateur pour créer un nouveau PDF.

5. Téléchargez et vérifiez

Téléchargez le résultat et vérifiez son affichage ainsi que les exigences du service où vous l'enverrez.

Confidentialité dès la conception

Le traitement normal est conçu pour rester local dans le navigateur plutôt que d'envoyer le PDF à un serveur de compression distant.
