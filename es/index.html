Cómo comprimir un PDF a un tamaño específico

  1. Sube tu PDF: Elige un PDF o arrástralo al compresor.
  2. Introduce el tamaño objetivo: Selecciona 100 KB, 200 KB, 500 KB o 1 MB.
  3. Comprimir the PDF: Click Comprimir and let the browser optimize the file toward your target.
  4. Descarga el resultado: Descarga el PDF comprimido cuando termine el proceso.

Por qué usar este compresor de PDF

Establecer un tamaño específico

Set a target in KB instead of choosing only a generic compression level. This is useful when an application, form or website has a file-size limit.

Proceso sencillo desde el navegador

Upload a PDF, choose a target, compress it and download the result without installing desktop software.

La calidad se protege primero

The compressor first attempts to preserve quality and only makes stronger reductions when the requested target requires them.
